# Privacy Policy

**Markdown Reader** does not collect, sell, or transmit personal information.

The extension processes Markdown content locally in the browser to render the reading view. It may fetch the currently opened Markdown URL and its parent directory when the folder browser or hot reload feature is used. Those requests are made by the browser to the URL already opened by the user and are not sent to a service operated by this project.

User preferences, including theme, language, layout, enabled plugins, and panel settings, are stored locally with Chrome's extension storage. The project does not use analytics, advertising, user accounts, remote code, or external tracking services.

For privacy questions, open an issue in the project's GitHub repository.
